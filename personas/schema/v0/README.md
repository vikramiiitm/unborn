# Persona Schema v0

This is the first concrete schema for an Unborn Persona.

It is deliberately rich enough to support:
- Coherent identity and taste
- Circadian presence
- Engagement philosophy
- Short + long-term memory hooks
- Future conversational and agentic expansion
- Customer ownership tracking

The schema will evolve via versioned updates (v0 → v1 → …). All changes that affect the shape of the object will get an ADR.
