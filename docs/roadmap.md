# Roadmap

## Phase 1 – Sellable MVP
Goal: A customer can install on Ubuntu, activate a license, spin up multiple isolated Redroid instances with unique identity + proxy, and run basic realistic behavior.

- [ ] One-command installer (Ubuntu version, kernel modules, Docker checks)
- [ ] Docker Compose core + management images
- [ ] Orchestrator skeleton (start/stop/list instances)
- [ ] Per-instance network isolation + proxy injection
- [ ] Basic device identity generation & injection
- [ ] License service (signed keys, max instances)
- [ ] Simple statistical / rule-based behavior engine
- [ ] Resource limits + health checks
- [ ] Minimal CLI + basic dashboard

## Phase 2 – Realism Leap
Goal: Personas start feeling like real people from a niche.

- [ ] Full Persona object model + storage
- [ ] High-quality correlated sensor + touch trajectory generation
- [ ] Frida-based injection path (with path toward custom HAL)
- [ ] Vision-Language model for UI understanding
- [ ] Basic Detection Radar (CAPTCHA, integrity, reach signals)
- [ ] Persona DNA generator from natural language

## Phase 3 – Moat Features
Goal: Category-defining differentiation.

- [ ] Self-improving behavior models (opt-in learning)
- [ ] Goal-oriented adaptive agents
- [ ] Long-term persona memory & evolution
- [ ] Natural Language Persona Studio
- [ ] Population-level realism (small coherent communities)
- [ ] Synthetic data flywheel
- [ ] Cross-platform persona consistency (future)
- [ ] Customer-specific fine-tuning

---

Priority order inside each phase will be refined as we implement.
