## Current Truth (Short)

- We are a **farming system**.
- The moat is that **every body has a Persona (soul)**.
- We operate at **meaningful population scale** (tens → hundreds+), not tiny demo pods.
- We optimize for **sustainable, believable attention**, not disposable volume.
- Personas later become reusable (conversation, MCP tools, other surfaces).
- Responsibility is modular. Core modules run at full power. Guardrails are separate.
