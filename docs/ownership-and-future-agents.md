# Persona Ownership & Future Agentic Direction

## Ownership Model (Locked) — Hybrid

| What | Owner | Notes |
|------|-------|-------|
| Base / Template Persona DNA | Unborn | Continuously improved starting points for common niches |
| Customized or customer-created Personas | Customer | Full ownership |
| Lived memory & history during customer use | Customer | Even if started from a template |
| Engine, models, generation system | Unborn | Core IP |
| Anonymized aggregated learnings | Unborn (opt-out available) | Used to improve base templates and engine |

**Product language:**
> You own the Personas you create or customize.  
> We own the engine and the base templates.  
> Your Personas’ memories stay yours.

This model maximizes trust for agencies and brands while still letting us build a strong proprietary foundation.

## Future Direction: Personas as Agentic Beings

Year 1 focus remains: coherent presence and believable behavior on current surfaces (starting with social/Android).

However, the architecture and Persona object are deliberately designed so that in the future a Persona can become much more:

### 1. Conversational Interface
People (customers or end users) will be able to talk directly with a Persona.  
The Persona responds in character, with memory, taste, and continuity.

### 2. Tool Use via MCP Servers
A Persona will be able to act through MCP (Model Context Protocol) servers.  
This means a Persona can eventually:

- Use tools
- Browse
- Call APIs
- Control software
- Perform multi-step tasks
- Operate across different environments

…while still remaining the same coherent individual (same memory, personality, constraints, and history).

### Architectural Implication

The Persona is the **soul + memory + identity + preferences**.  
The current Redroid/Android body is only one possible body.  
MCP tool access becomes another way the same soul can act in the world.

This is why we keep:
- Hard separation between Persona Intelligence and any specific execution runtime
- Rich, portable, versioned Persona objects
- Long-horizon memory from early on

Year 1 we teach them to *exist* believably.  
Later we give them the ability to *act* more broadly — still as themselves.

---

## Principle

We do not rush the agentic layer.  
We first make the Persona real enough that talking to it or giving it tools feels meaningful instead of gimmicky.

Presence and coherence first.  
Capability expansion second.
